Firstly explain how SVM (Support vector machine) would work on my example.

A Support Vector Machine (SVM) tries to find a hyperplane that separates classes in feature space.
Each time sample becomes a feature vector: x(t) = [sig1(t), sig2(t), sig3(t), sig4(t)],
if we use time window(s): x(t) = [sig1(t - w), ..., sig4(t + w)]

An SVM classifier does not depend on how frequently events occur in time.
It depends on:
- Number of labeled training samples per class
- Class separability in feature space
- Class balance

What matters for SVM:
SVM performs better when:
- Each class has enough training examples
- Classes are not extremely imbalanced
- Features contain discriminative information

Rule of thumb for SVM:
- <10 samples per class = unstable boundary
- 20–50 samples per class = minimally workable
- 100+ per class = good baseline performance
