Firstly explain how SVM (Support vector machine) would work on my example.

A Support Vector Machine (SVM) tries to find a hyperplane that separates classes in feature space.
Each time sample becomes a feature vector: x(t) = [sig1(t), sig2(t), sig3(t), sig4(t)],
if we use time window(s): x(t) = [sig1(t - w), ..., sig4(t + w)]

An SVM classifier does not depend on how frequently events occur in time.
It depends on:
- Number of labeled training samples per class
- Class separability in feature space
- Class balance

What matters for SVM:
SVM performs better when:
- Each class has enough training examples
- Classes are not extremely imbalanced
- Features contain discriminative information

Rule of thumb for SVM:
- <10 samples per class = unstable boundary
- 20–50 samples per class = minimally workable
- 100+ per class = good baseline performance

Important: we will use SVM from sklearn: sklearn.svm.SVC, use SVC(class_weight="balanced")

STEP 1: Load Signal Data
========================
- Read signals from Excel file (sigs_X_df.xlsx)
- Expected columns: time_s, sig_1, sig_2, sig_3, sig_4
- Keep full signal timeline (no filtering)
- Store as pandas DataFrame, sorted by time_s


STEP 1b: Load Event Ground Truth (Interval-Based)
==================================================
- Read events from Excel file (events_X_df.xlsx)
- Expected columns: time_start, time_end, eID
- Events are intervals with start and end times
- Store as pandas DataFrame, sorted by time_start


STEP 2: Clean and Validate Time Alignment
===========================================
- Check that every event interval [time_start, time_end] falls within signal time range
- Validate: event_start < event_end
- Raise error if validation fails (no auto-correction)
- Output validation report with status and detailed issues


STEP 3: Create Label Vector
==============================================================
Map event intervals to signal samples:

Process:
1. Create mapping: event_id_string → numeric_label (1, 2, 3, ...)
2. Initialize all signal rows with label = 0 (no event)
3. For each signal sample at time t:
   - Check if t falls within ANY event interval [time_start, time_end]
   - If multiple events overlap at time t, use latest event (by start time)
   - Otherwise keep label = 0
4. Result: DataFrame [time_s, sig_1, sig_2, sig_3, sig_4, label]


STEP 4: Feature Extraction with Sliding Window
================================================
- Extract features using temporal context around each sample
- Window: ±2 samples = ±0.1s at 20Hz sampling rate
- For each sample t: extract signals from [t-2, t-1, t, t+1, t+2]
- 4 signals × 5 time points = 20 features per sample
- Handle boundaries by repeating edge values


STEP 5: Build X and y for sklearn + Train/Test Split
=======================================================
- X: Feature matrix (N_samples, 20 features)
- y: Label vector from Step 3 (N_samples,)
- Keep full timeline (including no-event samples)
- Train/Test split: 70% training / 30% testing (temporal split)
- Maintains chronological order for realistic evaluation


STEP 6: Handle Class Imbalance
================================
Problem: Most samples are label=0 (no event), creating severe imbalance
Solution: Use class_weight="balanced" in SVM
- Automatically reweights classes inversely proportional to frequency
- Prevents model from always predicting "no event"
- Critical for detecting minority event classes


STEP 7: Feature Scaling (StandardScaler)
==========================================
- SVM is highly sensitive to feature magnitude
- Procedure:
  1. Fit scaler on training features ONLY
  2. Transform training features
  3. Transform test features using SAME scaler (prevent data leakage)
- Result: All features normalized to mean=0, std=1


STEP 8: Train SVM Model
========================
Algorithm: sklearn.svm.SVC
- Kernel: "linear" (simple interpretable baseline)
- class_weight: "balanced" (handles class imbalance)
- decision_function_shape: "ovr" (one-vs-rest for multiclass)
- Input: X_train_scaled, y_train
- Output: Trained SVM model with decision boundaries


STEP 9: Make Predictions on Test Set
=====================================
- Apply trained model to X_test_scaled
- Output: y_pred (per-sample predictions, 0 or 1/2/3/...)
- One prediction per sample

STEP 10: Convert Point Predictions to Event Intervals (NEW)
===========================================================

Problem: SVM outputs per-sample predictions, but ground truth has event intervals
Solution: Detect state transitions to infer event boundaries

Algorithm (State Machine):
  - Track current_label starting at 0
  - Scan predictions with timestamps
  - Detect transitions:
    * 0 → non-zero: event starts
    * non-zero → different: previous ends, new starts
    * non-zero → 0: event ends

Post-Processing (Duration Constraints):
  - Filter events < min_duration_s (default: 1.0s) - removes noise
  - Cap events > max_duration_s (default: 7.0s) - prevents unrealistic events
  - Convert numeric labels back to event_id strings

Output: DataFrame [time_start, time_end, eID]

This step enables compatibility between point predictions and interval ground truth.

================================
- Save predicted event intervals to Excel file
- Format: [time_start, time_end, eID]
- File: predicted_events_svm.xlsx
